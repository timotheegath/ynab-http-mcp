# Targeted budget health tools

## Brief

Research friction points with the users of the YNAB budgeting app related to budget health where:

- The user might be having a lot of information but not knowing what to do with it
- The user is performing repetitive tasks that are not repeateable enough to be solved by standard automation algorithms

*Goal*:
Identify targeted value-adding functionality for a YNAB MCP
Streamline the MCP toolset to those tools
Provide an opinionated toolset to monitor budget health

### Out of scope (for now)

- Data hygiene issues
    These issues don't fit well an MCP use case, but could rather be an AI-driven cleanup automation.
